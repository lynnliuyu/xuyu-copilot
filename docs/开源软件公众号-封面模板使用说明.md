## 二、视觉规范（改稿时别破坏这三条）

**配色三档，不要加第四色：**

| 角色 | 色值 | 用在哪 |
|---|---|---|
| 主色 | `#0E1116` 近黑 | 全部背景 |
| 强调 | `#C8FF3D` 酸绿 | 标签胶囊、标题末行、字号表标题 |
| 辅助 | `#8B94A3` 灰 | 副标、说明、页脚 |
| 正文 | `#FFFFFF` 白 | 标题主体、要点 |

**字体只用一族人：`Source Han Sans CN`（思源黑体）**
- 大标题 → `Heavy`
- 副标 / 要点 → `Medium`
- 说明 / 页脚 → `Regular`

**字号表（px）：**

| 位置 | 小红书封面 | 小红书内页 | 视频号封面 |
|---|---|---|---|
| 标签胶囊 | 32 | 32 | 32 |
| 主标题 | 140 | 88 | 116 |
| 副标 / 要点 | 38 | 44 | 36 |
| 底栏 | 36 / 30 | 36 / 30 | 34 / 30 |

⚠️ **底线 28 px**，任何文字不得小于此值。放不下就**删字**，不要缩字号。

## 三、标题怎么写（规则比视觉重要）

**硬约束：标题 ≤ 12 字，分 2–3 行，末行用酸绿。**

首行必须是**反差或结论**，不能是介绍：

| ✅ 这样写 | ❌ 不要这样写 |
|---|---|
| 剪贴板软件 / 别再付订阅费了 | Maccy · 开源剪贴板工具 |
| 两台电脑传文件 / 别再发微信了 | LocalSend · 局域网传输工具 |
| 录屏还要买软件？/ 这个免费开源更强 | OBS Studio · 录屏推流工具 |

规律：**左列是"你的处境"，右列是"这东西叫什么"。** 公域只吃左边那种。

## 四、一条小红书笔记的 6 张图（固定结构）

复制模板 ② / ③，按这个顺序出图：

| 图 | 用哪个模板 | 内容 |
|---|---|---|
| 1 | ② 封面 | 钩子标题 + 软件截图 |
| 2 | ② 改（**去掉截图位**，标题换痛点句） | 你在为它付钱 / 受什么折磨 |
| 3 | ③ 内页卡 | 它能做什么（✓ 清单，4 条以内） |
| 4 | ③ 改（✓ 换掉） | 实测细节：体积 / 是否公证 / 最低系统 / 架构 |
| 5 | ③ 改（✓ 换 1️⃣2️⃣3️⃣） | 安装三步 |
| 6 | ② 改（标题换成"怎么拿到"） | 引导：同名公众号 + 回复关键词 |

> 第 4 张是最容易被忽略、但最值钱的一张 —— **"已通过 Apple 公证 / 不用绕 Gatekeeper"** 这类事实就是转化的关键。

## 五、怎么用（流程图）

```
复制画板 → 换掉文字 → 拖入真实截图 → 导出 PNG → 发
```

1. **改文字**：选中文本节点，直接改内容。标题换行了就手动加换行，别让它自动折行。
2. **换截图**：选中「截图位」这个方框 → 用图片填充替换掉占位图。截图建议宽度 ≥ 1600 px，否则会糊。
3. **导出**：选中画板 → 导出 PNG，**2x 倍图**。小红书会自动压缩，导出尺寸大一些更安全。
4. **别改的东西**：配色、字号、底栏结构。改坏了就从 ① 号画板对回来。

## 六、常见错误

| 错误 | 后果 |
|---|---|
| 标题写成"XX 是什么" | 公域没人点，这是最高频的错 |
| 封面加了店铺名 / 价格 | 被判硬广，限流 |
| 把小红书的方图直接当视频号封面 | 视频号是 9:16 竖版，方图会被裁掉两侧 |
| 截图位空着就发 | 没有"证据"，说服力掉一半 |
| 为了塞下文字把字号调小 | 缩到 28 以下等于无效输出，删字才对 |
