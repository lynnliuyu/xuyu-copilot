# 换电脑继续开发：迁移手册

> 适用：把开发工作副本从这台 Mac 搬到另一台电脑，**线上服务不中断**。

---

## 0. 先分清「三层」，避免搬错东西

| 层 | 在哪 | 迁移时怎么办 |
|---|---|---|
| **生产服务** | 黑豹X2 `<SERVER_IP>`（armbian / RK3566 / aarch64）上的 Docker，源码 `/opt/bdpan-goofish` | **完全不用动**。迁移期间闲鱼店铺照常自动发货 |
| **公网入口** | 中继机 `150.158.3.164` 的 Caddy + 134 上的出站隧道 | **不用动** |
| **开发工作副本** | 这台 Mac 的 `~/WorkBuddy/百度网盘mcp` | **要搬的就是它** |

「换电脑」= 换一个能读写代码、能连 134、能发商品的地方。**线上不会因此停一秒。**

---

## 1. 一条命令打包（在旧 Mac 上跑）

```bash
cd ~/WorkBuddy/百度网盘mcp
bash scripts/_make-migration-bundle.sh
```

| 参数 | 用途 |
|---|---|
| 默认 | 代码 + 草稿 + 密钥 + 记忆 + git 历史（**约 13 MB**，1360 多个文件） |
| `--no-git` | 不要提交流水（更小） |
| `--with-assets` | 连 `assets/` 全量（**+3 GB**：网盘商品图与安装包原件） |

产物落在 `out/migrate/`：

```
bdpan-goofish-migrate-<日期>.tar.gz.enc          ← AES-256 加密整包
bdpan-goofish-migrate-<日期>.tar.gz.enc.sha256
```

⚠️ 脚本会随机生成 **24 位解密密码并只打印一次**，立刻记进密码管理器（同一份也写在 `out/_migrate.log`，确认记好后建议删掉该日志）。

⚠️ 打包脚本末尾有**硬断言**：`.env` 和 `drafts/.listings.json` 少一个就直接 `exit 1`，不给包。原因：曾经因为 `03-secrets/drafts/` 目录没建，`cp` 静默失败，**上架台账 755 条压根没进包而日志看起来一切正常**——新机上就等于失忆，会重复上架已有商品。

## 2. 包里到底装了什么

| 内容 | 为什么必须在包里 |
|---|---|
| `01-code.tar.gz` | 工作区**实际内容**（含 910 个未提交改动：**758 份商品草稿**、105 个脚本、记忆库、37 个 skills…）。git 里没有的改动也在这 |
| `01b-out-scripts.tar.gz` | `out/` 里那些**只在 134 上跑过、不在 git 里**的运维脚本（`drip-shunhe.mjs` 滴灌器、`_artcraft-copy-push.mjs` 推送器、修数据脚本…）。恢复时解到 `out/` |
| `02-git.bundle` | 完整提交历史，可 `git clone` 回来回溯 |
| `03-secrets/.env` | 闲管家 app_secret、网关密钥等，**被 .gitignore 忽略**，GitHub 上没有 |
| `03-secrets/.tokens.json` | 百度网盘 OAuth token |
| `03-secrets/drafts/.listings.json` | **上架台账**（`code → product_id/item_id/状态`），被忽略，丢了等于失忆 |
| `03-secrets/drafts/.excluded.json` | 永久排除名单 |
| `03-secrets/out/netdisk-*.json` | 网盘目录索引与分享链接台账 |
| `03-secrets/ssh/xgj-134_ed25519` | 连生产机 134 的私钥 |
| `03-secrets/ssh/config` | SSH 别名 `xgj134` 的定义 |
| `03-secrets/keys/*.pem` | 中继机 `150.158.3.164` 的密钥（`.env` 里 `MEDIA_SSH_KEY` 传商品图、`TUNNEL_SSH_KEY` 建反向隧道）。**之前漏收过**，新机上 `npm run media:netdisk` 会报找不到私钥 |
| `03-secrets/bdpan/*` | 百度网盘 CLI 授权凭据（含点开头的 `.token_key`） |
| `03-secrets/bin/*.sh` | `fmkj-admin-forward.sh` 等本地隧道脚本 |
| `03-secrets/bin/bdpan` | 网盘 CLI 二进制（**Mach-O arm64**，非 Mac 请删掉重下） |
| `03-secrets/launchagents/*.plist` | 开机自启配置 |
| `04-env.txt` | 打包时的 node/npm/python/bdpan 版本，新机照此对齐 |

**assets 的处理**（易错点）：默认**不搬图片和安装包**（3 GB），但会把 `assets` 里的
**代码类文件一并收进去（85 个：`banned-words.json` 词表、`card-*.mjs` 封面模板、
`brand-icons/*.svg`、`free-software/*.json` 清单…）**。

> ⚠️ 为什么专门强调：`assets/_shared/banned-words.json` 是 `preflight` 的必需词表。
> 少了它**不会报错**，只会让「上架体检」静默失效 —— 既拦不住违禁词，也可能直接发不出去。

## 3. 新电脑准备

### macOS（推荐，和现在完全一致）

```bash
# 1) Node 22（项目实测 v22.22.2）
brew install node@22

# 2) Python 3.12+（部分脚本用到 3.10+ 语法）
brew install python@3.12

# 3) Chrome（出商品图 / 打印中文 PDF）
brew install --cask google-chrome

# 4) 可选：Docker Desktop —— 只有要在本地跑容器才需要；生产在 134
```

### Windows

**单独一份手册：[迁移到Windows.md](./迁移到Windows.md)**（装什么、几条命令、验证清单、哪些能力会降级）。

要点速览：

| 组件 | 需要改 |
|---|---|
| 恢复脚本 | 用包里的 `restore.ps1`（PowerShell），不是 `restore.sh` |
| 脚本里的家目录 | `node scripts\_retarget-paths.mjs --to "C:/Users/你" --apply` |
| `bdpan` CLI | 包内是 Mach-O arm64 → 重装 `windows-amd64.exe`（见 Windows 手册第 6 节） |
| `~/bin/*.sh` + launchd | 换成 `scripts\_windows-tunnel.ps1`（计划任务） |
| Chrome 路径 | 设 `CHROME_PATH` 环境变量 |
| 图片体检 OCR | macOS Vision → tesseract，**会降级**（人像/暴露识别直接没有） |

## 4. 恢复（推荐：一条命令）

```bash
# ① 传包（AirDrop / U 盘 / 网盘都行），并校验完整性
shasum -a 256 -c bdpan-goofish-migrate-*.tar.gz.enc.sha256     # 期望 OK

# ② 解密（会解出 bdpan-goofish-migrate-<日期>/）
openssl enc -d -aes-256-cbc -pbkdf2 -in bdpan-goofish-migrate-<日期>.tar.gz.enc | tar -xzf -

# ③ 建空目录并进入（恢复脚本会在「当前目录」展开代码）
mkdir -p ~/WorkBuddy/百度网盘mcp && cd ~/WorkBuddy/百度网盘mcp

# ④ 预演：只打印要做什么，不动任何文件
bash <迁移包目录>/bdpan-goofish-migrate-<日期>/restore.sh <迁移包目录>/bdpan-goofish-migrate-<日期>

# ⑤ 确认无误后执行
bash <迁移包目录>/bdpan-goofish-migrate-<日期>/restore.sh <迁移包目录>/bdpan-goofish-migrate-<日期> --apply
```

恢复脚本会自动完成：解代码 → 放回 `.env` / 台账 / SSH 私钥 / 中继机 pem / bdpan 凭据 / `~/bin` 脚本 / plist
→ 把 `.env` 里指向旧机器的 pem 绝对路径改成本机 `~/.ssh/…` → `npm ci`。
**默认预演，加 `--apply` 才动文件**；`~/.ssh/config` 已存在时不会覆盖，只打印要合并的片段。

### 想手动做（等价命令）

```bash
cd ~/WorkBuddy/百度网盘mcp
S=~/Downloads/bdpan-goofish-migrate-<日期>
tar -xzf "$S/01-code.tar.gz" -C .
cp -p "$S/03-secrets/.env" "$S/03-secrets/.tokens.json" ./
cp -p "$S/03-secrets/drafts/.listings.json" "$S/03-secrets/drafts/.excluded.json" drafts/
cp -p "$S/03-secrets/out/"*.json out/
mkdir -p ~/.ssh && cp -p "$S/03-secrets/ssh/xgj-134_ed25519"* ~/.ssh/ && chmod 600 ~/.ssh/xgj-134_ed25519
mkdir -p ~/.config/bdpan && cp -p "$S/03-secrets/bdpan/"* "$S/03-secrets/bdpan/".* ~/.config/bdpan/ 2>/dev/null
mkdir -p ~/bin && cp -p "$S/03-secrets/bin/"*.sh ~/bin/ && chmod +x ~/bin/*.sh
cp -p "$S/03-secrets/bin/bdpan" ~/.local/bin/ && chmod +x ~/.local/bin/bdpan
cp -p "$S/03-secrets/launchagents/"*.plist ~/Library/LaunchAgents/
npm ci
```

### 路径提示（容易踩）

`com.fmkj.admin-forward.plist` 里**写死了** `/Users/noonebook/bin/fmkj-admin-forward.sh`。
新机用户名不是 `noonebook` 时必须改：

```bash
grep -rn "/Users/noonebook" ~/bin/*.sh ~/Library/LaunchAgents/*.plist
sed -i '' "s|/Users/noonebook|$HOME|g" ~/Library/LaunchAgents/com.fmkj.*.plist
```

| # | 命令 | 期望 |

## 6. 脚本搬不动、必须你亲手做的 3 件事

1. **装载 launchd**（本项目沙箱里一律装不上，必须你自己终端跑）：
   ```bash
   launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.fmkj.admin-forward.plist
   launchctl list | grep fmkj
   ```
2. **验证网盘 CLI 授权**：`bdpan whoami`。换机后若 token 失效，重新走一次授权。
3. **确认商品图 CDN**：`curl -I https://xgj.fmkj.top/goods/figcraft-v2.png` 应为 200。
   （铁律：**同域名即图床**，改域名必须连图床一起改。）

## 9. 迁完之后、第一次发布前

1. **节流 300s/条**（服务端护栏，前端按钮绕不过）。
2. **上架前跑 `npm run preflight`**（文字 + 图片 OCR）。`GPT` 是 block 级禁词，图片里出现也会封。
3. **判成功只认 `item_id > 0`**；`publish.run` 返回 ok 只是「提交时刻」状态。
