六、整理已执行（附能力边界更正）

更正：上一版报告说「AI 改不了你的文件」——这个结论是错的，已经推翻

当时的判断基于一组错误结论。真正的原因不是权限，而是百度 xpan 写接口的参数位置有反直觉的约定：

参数放法结果
method 放进 bodyHTTP 400 error_code=3 Unsupported open api（误判为"接口未开通"）
所有参数都放 queryerrno=2 参数错误
method 放 query + 其余参数放 bodyerrno=0 成功 ✅

逐接口确认后的正确写法：

mkdir        : query = method, access_token
               body  = path, isdir=1, rtype
filemanager  : query = method, access_token, opera, async
               body  = filelist(JSON)
