# 一商品一链接，分享设为永久

发货内容是一条网盘链接。链接一旦随卡密发出去就改不回来，所以每个商品绑定一个专属分享链接，创建时设「永久」有效期（`-d 0`），链接写进发货模板固定复用；货源用 `stock_mode=shared`。

这样买家在任何时候打开卡密，都不会遇到「链接已过期」这种只能靠客服兜底的售后。

## Considered options

- **一商品一链接 + 永久分享**：影响面隔离，不会互相牵连。
- **共享一个链接**：改动一次影响所有商品，且泄漏时无法只废掉一个。
- **`pool` 模式**：仅在联调测试品上使用，不用于正式商品。

## Consequences

永久分享不可撤回。这正是选择「一商品一链接」的原因——把泄漏或失效的影响范围压到单个商品内，而不是整个货架。
