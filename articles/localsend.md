# LocalSend · 两台电脑传文件，别再发微信了

**同一个 Wi-Fi 下直接传，不经服务器、不用登录、不限速。Windows / macOS / Linux / 安卓互通。**

---

## 它解决什么问题

传一个几百 MB 的文件，手边的选择都不太顺：

- **微信**：压画质、限大小、还得两边都登录；
- **网盘**：要先上传再下载，等于走了两遍公网；
- **AirDrop**：只在苹果设备之间好使，和安卓、Windows 绝缘。

LocalSend 走的是最直接的一条路：**同一个局域网内，你的两台设备直接对接**。文件不经过任何第三方服务器，也不需要注册账号。

---

## 核心亮点

**1. 文件只在你两台设备之间走**

不经过任何服务器，也不上传到云。同一局域网内传，**断网（没有外网）也照样能用**——路由器和手机热点都行。

**2. 设备自动发现，拖进去就发**

打开就互相看见，不用输 IP、不用配对码。可以批量传照片、传整个文件夹。

**3. 苹果、安卓、Windows 互通**

这是它比 AirDrop 强的地方：**安卓 ↔ 苹果、安卓 ↔ Windows、Windows ↔ 苹果**都能传。家里设备不是一个牌子的时候，这条最关键。

**4. 传输本身是加密的**

走 HTTPS，**证书由每台设备现场生成**，不依赖任何中心机构。局域网上有人抓包，也拿不到内容。

## 安装

**Windows**　双击 `.exe`，下一步装完。若弹出 SmartScreen 蓝色警告，点「更多信息」→「仍要运行」。

**macOS**　双击 `.dmg` 挂载，把 LocalSend 拖进「应用程序」。首次打开若提示「无法验证开发者」，在「应用程序」里**右键点它 → 选「打开」→ 再点一次「打开」**。

**Linux**　`.AppImage` 免安装：先加执行权限，再双击。

```bash
chmod +x "LocalSend 1.18.2 - linux版(x86_64).AppImage"
```

**Android**　把 apk 传到手机后点击安装，系统提示「未知来源」时允许该来源即可（这是官方原包，不是第三方改包）。

## 常见问题

**两台设备互相看不见？**
八成是网络问题，按顺序排：① 确认在**同一个 Wi-Fi**（不是一台连 Wi-Fi 一台连热点）；② 路由器若开了「**AP 隔离**」要关掉，访客网络通常默认开着；③ 电脑上的**防火墙**会拦，第一次运行时记得允许通过。

**传得慢？**
局域网速度取决于 Wi-Fi 本身。同一个路由器尽量走 5 GHz 频段，或干脆用网线——能到几十 MB/s。

**安全吗？会不会被别人传东西给我？**
传输需要对方**确认接收**，不会静默写入。传输本身走 HTTPS，证书每台设备现场生成。

**能传整个文件夹吗？**
能。也可以传文本、传剪贴板内容。
