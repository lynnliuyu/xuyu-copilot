## 二、名称

### 规则（官方）

| 项 | 规则 |
|---|---|
次数 | 个人类型 **1 个自然年 2 次**（1 月 1 日重置） |
长度 | **4–30 字符**，1 个汉字算 2 字符；只允许**中文 / 英文 / 数字** |
路径 | 设置与开发 → 账号设置 → 名称 → 修改 → **主体本人微信扫码**（该微信须绑过银行卡） |
不命中保护词 | **24 小时确认期**，24 小时后才生效，期间可撤销 |
命中保护词 | 提交佐证材料，**7 个工作日**审核 |
生效后 | 粉丝会话框弹改名提醒；**历史文章仍显示旧名**（过渡期），新文章显新名；改名记录不可删除 |
原名称释放 | **2 天保护期**（同主体可立即复用；异主体需期满） |

> ⚠️ 注册名仍为「新注册公众号」时的首次改名 **不占用** 这 2 次额度。

### 三个选项（还差你一句话）

| | 做什么 | 代价 |
|---|---|---|
**A** | 公众号改成「**繁梦开源小仓库**」 | 烧掉 1 次命名额度 |
**B** | 模板全改成「**繁星软件安装管家**」 | 不烧额度，改 9 个本地文件 |
**C** | 换成第三个名字 | 告诉我，两边一起改 |

**我的建议：换名字，别用「软件安装管家」。** 三条理由：

1. **承诺与交付对不上** —— 读者看到「安装管家」预期是"你帮我装好"，而我们给的是官方原包 + 中文说明 + 授权依据。
2. **丢掉唯一的差异化** —— 你的护城河是"开源"，「安装管家」四个字里一点不含。而"提供软件下载安装服务"这类表述在各个平台都比"介绍软件"敏感。
3. **和公域昵称要对齐** —— 用户是从小红书/视频号看到你之后**手动搜**关注的。7–8 个字的通用名都难默写，所以三平台昵称必须完全一致；名字越长这个要求越难满足。

**但先别按下去。** 一年 2 次，建议：先在**小红书 / 视频号昵称**上用同名试（那两处可随时改），确认用户搜得到、记得住，再动公众号额度。

### 改名的正确姿势

名字定下来后，本地这些文件**一处都不要手工改**，跑一条命令：

```bash
npm run rename:account -- "繁梦开源小仓库"        # 先加 --dry 看会改哪几处
```

脚本会：① 先校验名字合规（长度 4–30 字符、只含中英文数字、不含「公众号」三字）；② 把旧名从 9 个文件里全部替换；③ 提醒你重出产物和手工改 Ardot 画板。

改完还要做：

```bash
npm run mp -- --all                                   # 重出封面与发布操作台（带落款）
npm run video:cards -- assets/video-specs/maccy.json  # 重出视频卡
```

1. **圆形安全区** —— 公众号头像在会话列表/资料页**按圆形显示**。四个候选的图形外接半径 98–117px，都 ≤ 安全值 138px，**四角不会被切**。

## 五、自定义菜单

### ⚠️ 先说一个坑：菜单和「服务器配置」会打架

未认证订阅号**在编辑模式下可以用自定义菜单**，但**一旦启用服务器配置，后台配的菜单就会失效**（消息全部转给我们那台服务，微信就不让后台再管菜单了，避免冲突）。这不是 bug，企业号也一样。

社区实测有效的解法（顺序不能反）：

```
1. 先停用服务器配置          → 设置与开发 → 基本配置 → 停用
2. 配菜单并保存发布          → 内容与互动 → 自定义菜单
3. 再启用服务器配置          → 菜单会立刻消失
4. 去「新的功能 / 新的作用」里把「自定义菜单」开启 → 菜单回来
```

**第 4 步存在与否取决于你后台版本**（微信后台改版频繁），以你实际看到的为准。如果找不到，就退回"没有菜单"的状态——不影响功能，关键词回复照常工作。

> 修改菜单时要重复这套流程（先停服务器配置）。

### 菜单方案（三个一级菜单，点击即发预设文字）

一级菜单名上限约 4 个汉字。「拿软件」「装不上」「关于」都合规。

**① 拿软件**
```
回复软件名，我直接把下载地址发你。

例：Maccy / LocalSend / OBS
不确定有哪些？回复「开源软件」看全部清单。
```

**② 装不上**
```
macOS：提示「无法验证开发者」
→ 在「应用程序」里右键点它 → 选「打开」→ 再点一次「打开」

Windows：弹出 SmartScreen 警告
→ 点「更多信息」→「仍要运行」

Linux：.deb 双击安装；.AppImage 先 chmod +x 再双击
还不行，把截图发我，我看看。
```

**③ 关于**
```
这里只做一件事：把官方发的开源软件，配一份能看懂的中文说明。

· 每个包都是官方原包，附官方 sha256，未做任何改动
· 每篇标注授权协议，GPL 类随包附源码获取方式
· 不收破解版、去授权版，也不提供商业软件
· 收到权利人通知会立刻下架
```

> **② 的价值被低估了**：它会挡掉大量重复提问，而这些提问现在每一条都要你人工回。

## 六、自动回复 / 关键词：**不用在后台设**

启用服务器配置后，后台的「自动回复」（被关注回复 / 关键词回复 / 收到消息回复）**全部失效**，消息转到我们那台服务上——**四类我们已经接管并实测过了**：

| 用户做什么 | 返回 |
|---|---|
新关注 | 欢迎语 + 全量收录清单（59 项） |
回复软件名（如 `Maccy`） | 下载地址 + 提取码 + 原项目地址 |
回复 `开源软件` / `目录` | 全量清单 |
没命中 | 引导文案 |

所以后台那一栏**保持空的就行，不必配**（配了也不会生效）。
