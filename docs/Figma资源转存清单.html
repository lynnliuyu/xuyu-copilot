4关键结论与限制

百度官方 Skill 的分享能力是可用的（本次实测）：bdpan share 成功生成外链，例如 https://pan.baidu.com/s/1gNCcm5ka53N0-iO1lpYGlQ?pwd=oqwu（7 天有效）。这与「百度分享接口需付费」并不矛盾 —— 付费墙卡的是我们自己那个开放平台应用（报 13998）；百度官方 Skill 背后的应用已购该能力。但它只能分享沙箱内的文件（/apps/bdpan/）。
夸克网盘同样可用 API 生成分享链接：夸克官方 Skill 自带分享能力，需要时可随时生成（可带提取码）。本次未生成。
⚠️ 百度官方 Skill 的 search 不受沙箱限制：ls / share / download 越界都会报「路径超出授权目录范围」，但 search 能搜到整个账号（实测搜「闲鱼商品分享链接管理」返回 95 条，含沙箱外的完整路径与打开链接）。它取不到文件内容，但文件名与目录结构是可读的 —— 与宣传中「物理隔离主盘数据」的说法有出入。
自研链路补充：官方 apaas/1.0/share/transfer 需要付费权限与未公开的 spwd，走不通；实际可用的是 shorturlinfo → share/verify（必须带 Referer）→ share/list 与 xpan/share?method=transfer（必须带 BDCLND cookie、sekey 传解码值）这条旧链路，已写入项目长期记忆供复用。
