# 开源软件公众号 · 推广与冷启动方案

> 前置文档：`开源软件公众号-运营方案.md`（内容与合规）、`首批选题与授权核验报告.md`（选题池）
> 本文只解决一个问题：**一个没有公域推荐流的新号，人从哪来。**

---

## 零、先纠正三个判断（否则后面全是白做）

### 0.1 公众号没有"推广位"，它只能承接

公众号（订阅号）对新号**几乎没有公域分发**。你发一篇，只有已关注的人能看到；「看一看 / 推荐流」需要账号权重和内容质量积累，前期约等于 0。

所以正确的结构是：

```
公域平台（有推荐算法，负责拉新）  →  公众号（无推荐，负责承接 + 沉淀 + 反复触达）
```

**你要推广的不是公众号，是那些能给你导流的公域内容。** 公众号是转化终点，不是起点。

### 0.2 你现在的选题方向，在公域平台不吃流量

现有文章的写法是「介绍这个开源软件是什么」（AppFlowy 是什么、LocalSend 是什么）。这个写法**只在已关注你的读者那里成立**——他已经在你的号里，才有耐心听介绍。

公域平台的用户是**刷到**的，不认识的。钩子只能是：

| 公域吃 | 公域不吃 |
|---|---|
| 你在为某个东西付钱 / 受折磨 | 这个项目技术架构如何 |
| 有信息差（"国外要收费，这个免费"） | Star 数多少 |
| 立刻能用的具体场景 | 功能列表逐条罗列 |

**结论：一篇文章要写两遍。** 公众号版 = 完整介绍；公域版 = 一个钩子 + 三句话 + 引导。

### 0.3 冷启动最容易死在哪

不是"内容不够好"，是这两件：

1. **导流话术太直白被限流。** 小红书/抖音对"关注 XX 公众号领取"极其敏感，写了就是限流甚至删除，白干。
2. **选错渠道。** 去 V2EX / 少数派发开源软件——那里的人比你更熟 GitHub，**他们不需要你**；而真正需要你的人是"不会翻墙、不知道 GitHub 是什么"的普通用户，他们在小红书和抖音。

## 一、渠道矩阵（按"该不该现在做"排序）

| 渠道 | 人群重合 | 内容形态 | 冷启动难度 | 导流友好度 | 判定 |
|---|---|---|---|---|---|
| **视频号** | 高 | 短视频 | 中 | ★★★★★ | ✅ **首选**，见 §5.1 |
| **小红书** | 很高（找免费工具的普通人） | 图文（多图卡片） | 低 | ★★ | ✅ **主力拉新** |
| **知乎** | 中高（吃搜索长尾） | 回答 | 高（吃账号权重） | ★★★★ | ✅ **长尾资产** |
| **酷安** | 极高（数码/玩机人群） | 图文帖 | 低 | ★★★ | ✅ 最精准，量小 |
| **自有网站**（你已有 `netdisk-site/`） | 全部 | 网页 | — | 无限制 | ✅ **长期资产** |
| 抖音 | 高、量最大 | 短视频 | 中高（要会剪） | ★★ | ○ 视频号跑通后再复刻 |
| B站 | 中高 | 中长视频 | 高（要养号） | ★★★ | ○ 你已有录屏类选题（OBS），可试 |
| 少数派 / 即刻 | 高（效率工具人） | 投稿 / 动态 | 中 | ★★★★ | ○ 种子用户 + 口碑，量小 |
| 贴吧 / 豆瓣小组 | 中 | 帖子 | 低 | ★★ | ○ 补充位 |
| 公众号「搜一搜」 | — | — | — | — | ⚙️ 被动，靠标题命中搜索词 |

**建议的起步配置：只做 3 个 —— 小红书（拉新）+ 知乎（长尾）+ 视频号（同生态转化）。** 一次铺 8 个渠道的结果一定是 8 个都做不起来。

### 1.1 为什么视频号是首选（这条最容易被忽略）

**视频号和公众号是同一个生态（微信）。**

这意味着三件事：
- 视频号主页可以**名正言顺**挂公众号名片 —— 这不违规，是官方支持的关联；
- 用户从视频号点进公众号，**不用跳 App、不用搜索、不用长按识别**，一步到位；
- 其他平台（小红书/抖音）导流到公众号是"跨平台挖人"，天然被防；视频号是"平台内部流转"，平台乐见其成。

**同样一条内容，视频号的转化率会显著高于任何外站。** 如果你的目标是公众号粉丝，视频号应该是主战场，小红书负责把不认识你的人拉进视野。

## 二、转化路径设计（三层漏斗）

```
第 1 层 · 公域钩子      小红书图文 / 短视频 / 知乎回答
        ↓  只讲痛点 + 效果，不放下载
第 2 层 · 承接           公众号（回复关键词 → 网盘链接 + 完整中文说明）
        ↓
第 3 层 · 沉淀           关注 = 下次更新还能触达（这才值钱）
```

**为什么必须绕公众号，而不是直接在公域给网盘链接？**

1. 小红书/抖音正文放网盘链接 = 导流违规，会被限流或删帖；
2. 链接改一次要改所有历史内容；放公众号关键词回复，改 `netdisk-links.json` 一处，全量生效；
3. **不关注 = 一次性流量**。用户拿走链接就走了，下次发新软件他还是不认识你。

⚠️ **漏斗长度是这套模式最大的成本。** 「刷到 → 感兴趣 → 打开微信 → 搜公众号名 → 关注 → 回复关键词 → 打开网盘」有 7 步，每一步都在流失。所以：

- **公众号名字要短、要好搜、要能凭直觉拼出来**（别用生僻字、别用英文+数字串）；
- 公域内容的**前 3 秒 / 封面**必须给出"这东西能解决我什么问题"，否则根本进不了第 2 步；
- 关键词要**极简**：用户大概率直接发软件名（`Maccy`），而不是发你规定的长词。

## 三、内容转型公式（公域钩子模板）

### 3.1 四种最吃流量的钩子

| 类型 | 模板 | 用在哪个项目 |
|---|---|---|
| **付费替代** | 「花 ¥XX 买的 XXX，其实有个 X MB 的免费开源替代」 | Maccy ↔ Paste（¥68/年）；AppFlowy ↔ Notion |
| **信息差** | 「国外卖 $XX 的软件，这个开源项目完全免费，中文可用」 | 通用 |
| **场景痛点** | 「两台电脑传文件，别再发微信 / 插 U 盘了」 | LocalSend |
| **省钱合集** | 「把我付费的 10 个软件，换成了这 10 个免费开源的」 | 合集型，最容易爆 |

### 3.2 合规词替换表（**必须遵守**）

公域平台对"破解"类内容打击极严，而且这也踩你自己的红线。发之前逐条比对：

| ❌ 不能写 | ✅ 改成 |
|---|---|
| 破解版 / 破解 / 绿色破解 | 开源项目 / 官方原包 |
| 白嫖 / 免费白嫖付费软件 | 开源替代（同类软件原本收费） |
| 永久免费 / 全网最低 / 最强大 | （直接删——绝对化用语，涉嫌违规且平台判广告） |
| 加我微信 / 关注 XX 领取 / 私信发你 | 同名公众号 / 主页自取 / 评论区 |
| 内购破解 / 去广告版 | 免费开源版 |

> 平台差异提醒：**「GPT」是闲鱼的封禁词**（图片里同样封），但公众号/小红书不适用这条——两边的词表不是一套，别把闲鱼的规则套到这边，也别反向套。

### 3.3 合集是最高效的形态

单篇讲一个软件，天花板很低。**「N 个替代付费软件的免费开源项目」这类合集，在公域平台的收藏/转发率显著更高**，而且一篇能带出 N 个关键词。

你手上的池子（65 条，按 Star 排序）足够拼出好几期合集：

- 《10 个能替代付费软件的免费开源工具》（Tabby / DBeaver / draw.io / IINA / LosslessCut…）
- 《装机必装：这些免费工具我用了三年》（Stats / MonitorControl / Etcher…）
- 《做设计不用买软件：开源创作工具清单》（设计创作类是你要覆盖的方向）

## 四、冷启动 30 天节奏

| 阶段 | 动作 | 目标 |
|---|---|---|
| **D1–D3** | 账号基建：公众号名字定稿、头像、简介、关键词回复表上线；小红书/知乎/视频号注册**同名**账号 | 先有名片 |
| **D4–D10** | **多平台试水**：同一篇内容改写成 3 个平台版本，同步发。观察哪类钩子有反应（不看粉丝，看互动率） | 找出 1 个有反应的渠道 |
| **D11–D20** | **聚焦**：押注表现最好的那个渠道，隔日更；其余渠道降到一周一条维持 | 该渠道跑出 1–2 条小爆 |
| **D21–D30** | **互推 + 长尾**：找 3–5 个同类小号互推；把爆过的话题改写成知乎回答（吃搜索） | 关注数上一个台阶 |

**发布时段**：小红书 19:00–22:00；公众号 07:30–08:30 或 20:00–21:00；知乎不限（吃的是搜索，不是时间）。

## 五、三个加速器

### 5.1 视频号同生态（见 §1.1，最高杠杆）

### 5.2 互推 / 换量 —— 最快的冷启动手段

找粉丝量级相近（500–5000）的**开源 / 效率工具 / 数码类**公众号互推。前期不用钱，互换一次推文位。

**一个 1000 粉的同类号推你一次，能带几十到上百关注** —— 比你单打独斗发两周内容还快。这是前期性价比最高的动作。

### 5.3 上游信誉资产（长线，但别人抄不走）

- 给收录的项目**提中文文档 PR**（哪怕只是补一段"如何在中文环境安装"）；
- 给 `awesome-*` 列表提 PR，把**你的中文说明站**收录进去；
- 项目作者看到 → 可能在你文章下发声 / 转发 → 这是**免费且高可信的背书**。

⚠️ **不要**去别人仓库的 Issues/Discussions 里发"我做了中文版，来看我的公众号"——那是骚扰，会被拉黑，反而砸牌子。

## 六、指标：别看粉丝数

公众号打开率目前普遍 **2%–5%**。1000 粉 ≈ 单篇 30 阅读。**粉丝数是个虚荣指标。**

真正要盯的是这两个：

| 指标 | 怎么测 | 健康值（前 3 个月） |
|---|---|---|
| **公域单条 → 公众号新增关注** | 发帖前后记录关注数差值 | 单条 ≥10 为及格，有爆款能到 50+ |
| **关键词回复次数**（= 真实下载需求） | 你的服务日志里已经记了 | 这才是真用户，比关注数诚实得多 |

> 你的 `wechat-reply-server.mjs` 天然是这个指标的数据源——它每次回复都能记下关键词与时间。**建议后续加一个 `out/wechat-stats.json` 累计回复次数**，用来判断"哪类选题真的有人要"，而不是猜。

**里程碑参考**：

| 关注数 | 意味着什么 |
|---|---|
| 100 | 有个名字了，可以开始互推 |
| 500 | 每篇有 10–25 阅读，值得持续投入 |
| 1000 | 具备互推议价能力；单篇 30+ 阅读 |
| 3000+ | 可以谈广告 / 带货（数码类目） |

## 八、已定路线（2026-10-09 锁定）

| # | 决策 | 定论 | 对打法的实际影响 |

| 1 | **主体** | **个人号先用着** | 见 §8.1 —— 有个必须现在想清楚的事 |

| 3 | **目标** | **先做影响力，后面再说** | 见 §8.3 —— 关键词回复**保持现状，什么都不用改** |

### 8.1 个人号：方案不受影响，但有一件事现在就得定

**好消息**：我们的关键词自动回复是**被动消息回复**，**未认证的个人订阅号完全支持** —— 服务已经实测跑通，这条路线不用动。

**但要知道的两条限制**：

- 个人主体**无法做微信认证**，部分高级接口（客服接口、网页授权等）用不了 —— 对当前目标**无影响**；
- 个人号**开不了微信支付** —— 将来想卖东西/收会员必须换主体，**有路径但要走主体变更流程，比较麻烦**。

⚠️ **所以真正要现在决定的是「名字」。** 公众号名称一年只能改 **2 次**且要审核，**起错名字的代价比换主体还烦** —— 所有已经发出去的内容、被别人记住的名字、关键词引导，都会对不上。

**取名四条约束**（按重要性）：

1. **能凭直觉拼出来** —— 用户是从小红书/视频号看到你，要**手动搜索**关注。生僻字、英文+数字串、需要解释的名字，都会在这步流失；
2. **和"开源软件"强关联** —— 名字里带「开源 / 工具 / 软件 / 仓库」这类词，用户搜的时候更容易命中；
3. **不要在个人号和将来的商业主体之间制造冲突** —— 如果你后面想用企业号做变现，现在的名字别绑死在某家店上；
4. 别蹭已被大号占用的名字，注册前先搜一遍。

### 8.2 不出镜：选题和封面逻辑反转

不出镜 = **画面上没有脸**。观众的全部注意力落在**界面和文字**上，所以：

**① 选题要偏向"界面可演示"的软件**

| 适合录屏 | 不适合 |
|---|---|
| Maccy（弹窗交互）· LocalSend（连设备）· IINA（播放）· Stats/MonitorControl（菜单栏）· draw.io（画图） | 纯命令行工具、纯后台服务、需要长期使用才见效的（笔记类） |

你候选池里 **57 条可打包**，UI 型占多数，够用很久。

**② 封面逻辑从"人脸"变成"截图 + 大字"**

有人脸的封面靠表情抓注意力；没有脸，**就只能靠信息密度和大字对比**。这意味着：

- 封面文案必须 **≤12 字**，且是**结论式**（"免费""4.5MB""替代 XX"），不是介绍式；
- 必须有一张**能一眼看懂的高对比截图**（Maccy 的历史列表、LocalSend 的设备连接界面）；
- 视频号封面 = 竖版 9:16 单独出图，**不能直接截用小红书方图**。

**③ 录屏本身的成本可控** —— 用 OBS 录（顺带自己吃一次狗粮，你把 OBS 那篇的配置说明也就实测过了）。口播改**字幕脚本**，不用开口，见 `out/promo/首发引流文案包.md` 里的口播稿（已按字幕排版）。

### 8.3 先做影响力：关键词回复什么都不用改

当前关键词回复给的是「网盘链接 + 中文说明」，**正好就是纯内容路线要的形态** —— 不需要挂店铺、不需要加价格锚点。

**只做一件事给未来留口子**：在 `netdisk-links.json` 里保留一个**目录型关键词**（回复「目录」/「合集」→ 输出全量 59 条清单）。将来无论走不走变现，一个能一次看到全部内容的入口都是资产。

⚠️ 明确不做：现在不要在任何位置出现店铺名、价格、"购买"。纯内容路线一旦掺了变现痕迹，公域平台会直接按硬广处理，前功尽弃。
