# 公网域名兼作商品图床

`xgj.fmkj.top` 同时承担两个职责：闲管家回调入口，以及商品图床（路由 `/goods/*` 映射到服务器的 `/srv/goods-img`）。共用一套域名是为了少一份证书和一份反代配置。

代价是这个名字被硬编码进了 741 条草稿的封面图 URL，也写进了 `.env` 的 `MEDIA_PUBLIC_BASE`。**换域名必须连图床一起换**，否则所有商品图当场挂掉。

## Consequences

2026-10-11 从 `api.fmkj.top` 迁到 `xgj.fmkj.top` 时，一次改动波及 750 个文件、1511 处引用。下次再换域名，按这个规模预估工作量，不要以为只是改一行配置。

旧域名已不属于本项目，不要再把它写回任何配置。
