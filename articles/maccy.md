# Maccy · 4.5 MB 的剪贴板历史（免费开源，替代付费的 Paste）

**按一下 `⇧⌘C`，就能翻出刚才复制过的所有东西。整个应用只有 4.5 MB，且已通过 Apple 公证。**

---

## 它解决什么问题

「刚才复制的那段话去哪了？」——再复制一段，上一段就没了。macOS 自带的剪贴板**只记一条**。

想留历史，App Store 里的 Paste、Pastebot 都是**订阅制**（Paste 约 ¥68/年）。

Maccy 只做一件事：**把复制过的内容全留住，随时翻回来**。而且只有 4.5 MB——比一张壁纸还小。

---

## 核心亮点

**1. 菜单栏应用，不占 Dock**

解包后 `LSUIElement = true`：它只在菜单栏有个小图标。对一个「偶尔用一下」的工具，这才是对的形态。

**2. 快捷键顺手，这是它比同类强的地方**

| 操作 | 快捷键 |
|---|---|
| 呼出历史面板 | `⇧⌘C` |
| 选中并粘贴 | `⌥ + Enter` |
| **粘贴为纯文本**（去掉格式） | `⌥⇧ + Enter` |
| 把某条固定在顶部 | `⌥P` |
| 删除某一条 | `⌥⌫` |

第 3 行最值钱：从网页复制来的文字常带一堆字号颜色，`⌥⇧Enter` 直接给纯文本。

**3. 本地优先，而且真的做了过滤**

历史只存在本机，不上传任何服务器；默认忽略密码管理器一类标记为机密的剪贴板内容。

临时不想被记录：**按住 `⌥` 点菜单栏图标**即暂停；`⌥⇧` 点图标只忽略下一次。

**4. 已通过 Apple 公证 —— 装完双击就能用**

这条最容易被忽略，却最影响体验。很多开源 macOS 应用只签名不公证，装完被 Gatekeeper 拦住，得去系统设置点「仍要打开」或右键绕一圈。

Maccy 实测为 `Notarized Developer ID`，且公证票据已装订。**不用绕，双击直接用。**

## 安装（三步，不到一分钟）

**第 1 步 · 解压**　双击下载到的 zip，得到 `Maccy.app`。

**第 2 步 · 拖进「应用程序」**　官方包已签名且已公证，**直接双击即可，不需要右键绕 Gatekeeper**。

**第 3 步 · 首次打开**　菜单栏出现小图标（**没有 Dock 图标是正常的**）。随便复制几段文字，按 `⇧⌘C`，历史面板弹出；方向键选，`Enter` 复制，`⌥Enter` 直接粘贴。

**顺手做两个设置**（按 `⌘,` 打开偏好设置）：把**开机自启**打开——不然重启后历史就断了；历史条数保持默认就够，调大纯占内存。

## 常见问题

**按 `⇧⌘C` 在某些输入框里没反应？**
这是 macOS 的机制：系统会屏蔽密码输入框里的全局快捷键。在密码框里请点菜单栏图标。

**`⌥Enter` 粘贴没反应？**
多半是**辅助功能权限**没给。系统设置 → 隐私与安全性 → 辅助功能，把 Maccy 勾上。

**历史里会不会存下我的密码？**
默认会过滤密码管理器一类标记为机密的内容，但**要保险就用 `⌥` 点菜单栏图标临时关闭记录**。

**能搜索吗？**
能。面板打开后**直接打字**就是过滤，不用先按搜索键。
