# OBS Studio · 录屏和直播，这一个免费的就够

**录屏 + 推流一体，Windows / macOS / Linux 全平台。开源免费，没有水印、没有时长限制。**

---

## 它解决什么问题

想录一段操作演示，或者开个直播，手边的选择都有点别扭：

- 商业录屏软件按年收费，**试用版还盖水印**；
- 免费的往往**捆绑一堆没用的东西**，装完还不知道装了啥；
- 想同时录屏幕和摄像头、还要分开调音量，多数工具做不到。

OBS 是这一类工具里的**事实标准**——各直播平台的教学文档，默认都按它来写。

---

## 核心亮点

**1. 「场景 + 来源 + 混音器」三区布局**

这是它最核心的设计：把「要播什么」（屏幕、窗口、摄像头、图片）和「怎么播」（切场景、调音量）**分成两层**。配好一次，之后就是按键切场景。

**2. 录制和推流用同一套画面**

配一次，录像和直播都能用。不需要为了发视频再录一遍——**录完直接就是能发布的文件**。

**3. 音频可以录多轨，后期单独调**

麦克风和系统声音分轨道录进同一个文件，后期能把某一路调小或单独剪掉。这一点在商业录屏软件里经常要加钱。

**4. 常用的都内置了**

绿幕抠像、降噪、色彩校正、画面裁剪、转场，还有多路画面自由摆放。插件生态也成熟，缺什么基本都有现成的。

## 安装

**Windows**　双击 `.exe` 装完即可。首次运行若弹出 SmartScreen 蓝色警告，点「更多信息」→「仍要运行」。安装时**不要选「为所有用户安装」**，可以少一次管理员授权。

**macOS**　双击 `.dmg`，把 OBS 拖进「应用程序」。首次打开会要求**「屏幕录制」权限**——必须授予，否则录出来是黑屏。若提示「无法验证开发者」，右键点它 →「打开」→ 再点一次「打开」。

**Linux（Ubuntu / Debian）**　双击 `.deb` 安装，或终端执行：

```bash
sudo apt install "./OBS Studio 32.2.2 - linux版(x86_64).deb"
```

## 常见问题

**录出来是黑屏、只有声音没有画面？**
权限问题。macOS 去「系统设置 → 隐私与安全性 → 屏幕录制」，把 OBS 勾上，然后**重启 OBS**。

**录不到系统内部的声音？**
麦克风很容易，系统声音在 macOS 上需要额外配置音频来源。**首次录音前先对着官方文档把音频来源配好**，别等录完才发现没声音。

**录出来的视频卡顿、掉帧？**
「设置 → 输出」里把编码器换成**硬件编码**（Apple 芯片选 `Apple VT H264`，Windows 选 `NVENC` 或 `QuickSync`），比 CPU 软编流畅得多。

**直播的推流地址和密钥填哪？**
「设置 → 直播」。各直播平台的后台都能生成这一对，粘贴进去即可。
